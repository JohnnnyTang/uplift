# Where plates meet: sources and the limits of their use

Citation keys in the deeper level and teacher notes resolve below and in `sources.ts`. The figure is an
**illustration**: its shapes are authored from these examples (D-L2-1), so the literature supplies the
real-world facts the text cites and the shape cues the drawing follows; it does not validate any process
in the scene, because none runs there. What session 7A actually read of each reference is recorded in
[docs/science/plates/sources.md](../../../docs/science/plates/sources.md); the full claim/source register is
[docs/science/plates/lesson/README.md](../../../docs/science/plates/lesson/README.md).
