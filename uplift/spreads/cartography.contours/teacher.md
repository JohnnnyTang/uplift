# Teaching the lifted contour

Invite the reader to drag the ring and name what remains the same. The heavy dashed contour is extracted from the actual triangulated hill: every vertex has the selected elevation above the model datum. Lift and vertical exaggeration are view transforms. This is an authored geometry demonstration, not a simulated mountain or real survey.

The displayed elevation, interval and exaggeration bind to the scene's geometry. The optional question is unscored; the explanation can be opened before any gesture. Changing reading level never changes terrain or lift. Reset restores the flat drawing and authored contour selection while keeping reading level.

Keyboard: use the native lift slider. In reduced motion lift follows the control directly. Static fallback keeps the real contour diagram and explanation; it does not invent a clock.

Source: [USGS, What is a topographic map?](https://www.usgs.gov/faqs/what-a-topographic-map). Independently checked the contour definition against the USGS Map Symbol Guide.
