# Sources for the plate-boundaries lesson (session 7A)

Every figure in [parameters.md](parameters.md), [reference-landforms.md](reference-landforms.md) and
[claims.md](claims.md) points to a key in this table. The status column says what this session actually
read on 2026-11-14:

- **read**: the full text, or the named section of it, was read and the quoted value found in it.
- **abstract**: only the abstract (or a publisher or agency abstract page) was read.
- **standard, not re-read**: a textbook reference cited for a standard relation; the relation itself was
  checked against the lecture notes named in the same row.
- **not verified**: listed so nobody uses it until it is checked.

An expert should confirm the values against the full texts before release, as for lesson 1
([glacial sources](../glacial/sources.md)).
