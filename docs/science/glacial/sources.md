# Sources for the glacier model (session 5G)

Status of each source is stated honestly: **read** means the session read the full text or the part
cited; **abstract/secondary** means only the abstract, a publisher summary or a citing paper was available
to the session (most of these are paywalled or scanned without a text layer). Every equation and
parameter in [model.md](model.md) points back to a row here. An expert should confirm the
abstract/secondary rows against the full texts before release. Bibliographic details (volume,
pages) of rows not marked **read** were written from the session's knowledge and must be checked too.
